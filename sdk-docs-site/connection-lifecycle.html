Connection Lifecycle

The complete flow from finding a server to establishing a VPN tunnel and reporting the session to the backend.

The Big Picture

sequenceDiagram
    participant User
    participant App as Your App
    participant SDK as FyreWay SDK
    participant API as Backend
    participant Tunnel as VPN Tunnel
    User->>App: Tap "Connect"
    Note over App,API: 1. Find a Server
    App->>SDK: smartConnect()
    SDK->>API: GET optimal server
    API-->>SDK: Server details
    SDK-->>App: SmartConnectResult
    Note over App,API: 2. Create a VPN Profile
    App->>SDK: createProfile(serverId)
    SDK->>API: POST create peer
    API-->>SDK: VPN config + credentials
    SDK-->>App: VpnProfile
    Note over App,Tunnel: 3. Establish VPN Tunnel
    App->>Tunnel: Connect using VpnProfile
    Tunnel-->>App: Tunnel established
    Note over App,API: 4. Report Connected
    App->>SDK: reportConnected(...)
    SDK->>API: POST connection state
    Note over User,Tunnel: User uses VPN...
    Note over App,API: 5. Disconnect
    User->>App: Tap "Disconnect"
    App->>Tunnel: Tear down tunnel
    App->>SDK: reportDisconnected()
    SDK->>API: POST disconnected state

Step 1 — Find a Server

// Option A: Automatic (recommended)
val result = sdk.smartConnect()
val server = (result as? VpnResult.Success)?.data?.server

// Option B: User picks from a list
val servers = sdk.getServersByCountry("US")
val server = (servers as? VpnResult.Success)?.data?.firstOrNull()

Step 2 — Create a VPN Profile

WireGuard Profile

Kotlin
val profileResult = sdk.createProfile(
    serverId = server.serverId,
    request = CreateProfileRequest(
        clientIdentity = "user@example.com",
        tier = "free",
        protocol = "wireguard",
        allowedIPs = listOf("0.0.0.0/0"),
        persistentKeepalive = 25,
        dns = listOf("1.1.1.1", "8.8.8.8")
    )
)

when (profileResult) {
    is VpnResult.Success -> {
        val profile: VpnProfile = profileResult.data

        profile.peerIdentifier       // YOUR client public key — use for reportConnected()
        profile.serverPublicKey      // Server's public key — goes in [Peer] section
        profile.endpoint             // "1.2.3.4:51820"
        profile.address              // "10.0.0.5/32" — your assigned IP

        val configText = profile.toVpnConfig()
        val rawConfig = profile.vpnConfig?.raw
    }
    is VpnResult.Error -> { /* Handle error */ }
}

OpenVPN Profile

val profileResult = sdk.createProfile(
    serverId = server.serverId,
    request = CreateProfileRequest(
        clientIdentity = "user@example.com",
        tier = "premium",
        protocol = "openvpn"
    )
)

when (profileResult) {
    is VpnResult.Success -> {
        val ovpnContent = profileResult.data.vpnConfig?.raw
        profileResult.data.peerIdentifier  // clientName (certificate CN)
    }
    is VpnResult.Error -> { /* Handle error */ }
}

Step 3 — Establish the VPN Tunnel

This is your responsibility. Use whichever tunnel library fits your app:

// WireGuard (pseudo-code)
val tunnelConfig = profile.toVpnConfig()
wireguardBackend.setState(tunnel, tunnelConfig, State.UP)

// OpenVPN (pseudo-code)
val ovpnConfig = profile.vpnConfig?.raw ?: ""
openVpnManager.startVpn(ovpnConfig)

Step 4 — Report Connected

Kotlin
sdk.reportConnected(
    serverId = server.serverId,
    serverName = server.name,
    peerIdentifier = profile.peerIdentifier,
    clientIdentity = "user@example.com",
    tier = "free",
    protocol = VpnProtocol.WIREGUARD
)

Understanding peerIdentifier

ProtocolWhat to sendWhere to get it
WireGuardClient's own public keyprofile.peerIdentifier
OpenVPNClient name (cert CN)profile.peerIdentifier
Important: Do NOT confuse with the server's public key (profile.serverPublicKey). The peerIdentifier uniquely identifies your device on the VPN server. It's optional — pass null if unavailable.

Step 5 — Disconnect

// 1. Tear down the tunnel
wireguardBackend.setState(tunnel, config, State.DOWN)

// 2. Report disconnection (no params needed)
sdk.reportDisconnected()
Note: reportDisconnected() takes no parameters. The backend identifies your device from the authentication token.

Observing Connection State

class VpnViewModel : ViewModel() {
    private val sdk = FyreWaySDK.getInstance()
    val connectionState: StateFlow<ConnectionState> = sdk.connectionState

    init {
        viewModelScope.launch {
            connectionState.collect { state ->
                when (state) {
                    ConnectionState.CONNECTED -> { /* Update UI */ }
                    ConnectionState.CONNECTING -> { /* Show progress */ }
                    ConnectionState.DISCONNECTED -> { /* Show disconnected */ }
                    ConnectionState.DISCONNECTING -> { /* Show progress */ }
                }
            }
        }
    }
}

In Compose

@Composable
fun ConnectionStatus(viewModel: VpnViewModel) {
    val state by viewModel.connectionState.collectAsState()
    Text(text = when (state) {
        ConnectionState.CONNECTED -> "🟢 Connected"
        ConnectionState.CONNECTING -> "🟡 Connecting..."
        ConnectionState.DISCONNECTED -> "🔴 Disconnected"
        ConnectionState.DISCONNECTING -> "🟡 Disconnecting..."
    })
}

Profile Management

// Get all stored profiles
val allProfiles = sdk.getStoredProfiles()

// Filter by protocol
val wgProfiles = sdk.getStoredProfiles(VpnProtocol.WIREGUARD)

// Get profile for a specific server
val profile = sdk.getStoredProfile(serverId = "wg-us-east-01")

// Delete a profile
sdk.deleteProfile(serverId = "wg-us-east-01")

// Clear all
sdk.clearStoredProfiles()

// Revoke on server
sdk.revokeClient(serverId = "wg-us-east-01", clientName = "user@example.com")

// Re-export config
sdk.exportConfig(serverId = "wg-us-east-01", clientName = "user@example.com")
