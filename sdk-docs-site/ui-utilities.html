UI Utilities

Pre-formatted display models, data providers, and formatters for building server lists, location pickers, and connection UIs rapidly.

ServerListProvider

// All servers, sorted by recommendation score
val servers = serverListProvider.getServersForDisplay()

// Servers in a specific country
val usServers = serverListProvider.getCountryServers("US")

// Best single server
val best = serverListProvider.getBestServer()

// Top 5 fastest (by latency)
val fastest = serverListProvider.getFastestServers(limit = 5)

The ServerDisplayItem

Every field is ready to render — no formatting needed:

data class ServerDisplayItem(
    val serverId: String,
    val name: String,               // "US East 01"
    val flagEmoji: String,          // "🇺🇸"
    val locationDisplay: String,    // "New York, US"
    val loadDisplay: String,        // "45%"
    val loadLevel: LoadLevel,       // LOW, MEDIUM, HIGH
    val latencyDisplay: String,     // "25ms"
    val latencyLevel: LatencyLevel, // EXCELLENT, GOOD, FAIR, POOR
    val isOnline: Boolean,
    val recommendationScore: Int   // 0–100
)

Format Utilities

// Country flags
CountryFlags.getFlag("US")     // "🇺🇸"
CountryFlags.getFlag("GB")     // "🇬🇧"

// Server load
ServerLoadFormatter.format(0.45f)        // "45%"
ServerLoadFormatter.getLoadLevel(0.3f)   // LOW

// Latency
LatencyFormatter.format(25)              // "25ms"

Extension Functions

// Convert Server → display model
val displayItem = server.toDisplayItem()
val displayItems = servers.toDisplayItems()

// Group for pickers
val countryItems = servers.toCountryPickerItems()
val cityItems = servers.toCityPickerItems()

// Filter & sort
val active = servers.activeOnly()
val sorted = servers.sortByRecommendation()
