Server Discovery

The SDK provides a rich set of APIs to browse, filter, and search VPN servers. All data is cached by default — you control when to use fresh data.

Location Model

Servers are organized in a geographic hierarchy. The region field represents a physical province or state (e.g., "Punjab", "Virginia", "Île-de-France"), not a cloud region code.

Fetching Servers

Basic: Get All Servers

when (val result = sdk.getServers()) {
    is VpnResult.Success -> {
        val servers = result.data.servers  // List<Server>
        val total = result.data.totalCount
        val fromCache = result.fromCache
    }
    is VpnResult.Error -> { /* Handle error */ }
}

With Format Control

The ServerFormat enum controls how much data is returned:

FormatUse caseData included
FULLServer detail viewAll fields: location, capacity, performance, protocols
MINIMALDropdowns, pickersID, name, location only
GROUPEDGrouped listsServers grouped by country or city
HIERARCHYNested tree viewsCountry → Region → City → Servers
 
// Full details (default)
sdk.getServers(format = ServerFormat.FULL)

// Lightweight for dropdowns
sdk.getServersMinimal()

// Grouped by country
sdk.getServersGrouped(groupBy = ServerGroupBy.COUNTRY)

// Tree structure for nested pickers
sdk.getServersHierarchy()

With Filters

// By country
sdk.getServers(filter = ServerFilter.byCountry("US"))

// By city
sdk.getServers(filter = ServerFilter.byCity("US", "New York"))

// By region (physical province/state)
sdk.getServers(filter = ServerFilter.byRegion("Virginia"))

// Custom filter
sdk.getServers(filter = ServerFilter(
    country = "US",
    city = "New York",
    status = "active"
))

Convenience Methods

// Servers in a country
val usServers = sdk.getServersByCountry("US")

// Servers in a city
val nycServers = sdk.getServersByCity("US", "New York")

// Servers supporting a protocol
val wgServers = sdk.getServersByProtocol(VpnProtocol.WIREGUARD)
val ovpnServers = sdk.getServersByProtocol(VpnProtocol.OPENVPN)

Location APIs

Country List

when (val result = sdk.getCountries()) {
    is VpnResult.Success -> {
        result.data.forEach { country ->
            println("${country.flagEmoji} ${country.name} (${country.code}) — ${country.serverCount} servers")
        }
    }
    is VpnResult.Error -> { /* Handle error */ }
}

Cities in a Country

when (val result = sdk.getCities("US")) {
    is VpnResult.Success -> {
        result.data.forEach { city ->
            println("${city.name} — ${city.serverCount} servers (${city.region})")
        }
    }
    is VpnResult.Error -> { /* Handle error */ }
}

Full Location Hierarchy

when (val result = sdk.getLocationHierarchy()) {
    is VpnResult.Success -> {
        result.data.countries.forEach { country ->
            println("${country.flagEmoji} ${country.name}")
            country.regions.forEach { region ->
                println("  📍 ${region.name}")
                region.cities.forEach { city ->
                    println("    🏙️ ${city.name} (${city.serverCount} servers)")
                }
            }
        }
    }
    is VpnResult.Error -> { /* Handle error */ }
}

Optimal Server (Backend Load-Balanced)

// Best server globally
val best = sdk.getOptimalServer()

// Best server in a country
val bestUS = sdk.getOptimalServer(country = "US")

// Best server in a city
val bestNYC = sdk.getOptimalServer(country = "US", city = "New York")

The Server Object

data class Server(
    val serverId: String,           // "wg-us-east-01"
    val name: String,               // "US East 01"
    val location: ServerLocation,   // Country, city, region, coordinates
    val capacity: ServerCapacity?,  // Utilization, available slots
    val performance: ServerPerformance?,
    val tier: String?,              // "free" or "premium"
    val status: String?,            // "active", "maintenance", "offline"
    val protocols: List<String>?    // ["wireguard", "openvpn"]
)

Protocol support check:

if (server.supportsProtocol(VpnProtocol.OPENVPN)) {

Caching

PolicyBehavior
CACHE_FIRSTReturn cached data if available; fetch from network only if cache is empty
NETWORK_FIRSTAlways try network first; fall back to cache on failure
CACHE_ONLYOnly use cache — fail if not cached
NETWORK_ONLYAlways use network — never cache
 
// Use cache (default)
sdk.getServers(useCache = true)

// Force fresh data (e.g., pull-to-refresh)
sdk.getServers(useCache = false)

// Clear cache manually
sdk.clearServerCache()
sdk.clearLocationCache()
