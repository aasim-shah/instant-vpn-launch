Smart Connect

One-call API that selects the optimal VPN server based on configurable strategies. No manual server selection logic needed.

How It Works

flowchart TD
    Start["smartConnect(criteria, strategy)"]
    Fetch["Fetch available servers"]
    Filter["Apply filters"]
    Score["Score each server"]
    Select["Select highest-scoring server"]
    Result["Return SmartConnectResult"]
    Start --> Fetch --> Filter --> Score --> Select --> Result

Basic Usage

when (val result = sdk.smartConnect()) {
    is VpnResult.Success -> {
        val server = result.data.server      // The selected Server
        val reason = result.data.reason      // "Balanced: best overall score"
        val score = result.data.score        // 0.0 – 1.0
    }
    is VpnResult.Error -> { /* Handle error */ }
}

Selection Strategies

StrategyBest forHow it scores
BALANCEDGeneral use (default)Weighted mix of load, latency, and capacity
LOWEST_LOADMaximum bandwidthFewest active connections
LOWEST_LATENCYGaming, real-timeLowest ping
HIGHEST_CAPACITYPeak hoursMost available slots
CLOSEST_LOCATIONLowest latency (geo)Geographic proximity
 
// For gaming
sdk.smartConnect(strategy = SelectionStrategy.LOWEST_LATENCY)

// During peak hours
sdk.smartConnect(strategy = SelectionStrategy.HIGHEST_CAPACITY)

// For downloads
sdk.smartConnect(strategy = SelectionStrategy.LOWEST_LOAD)

Filtering with Criteria

val result = sdk.smartConnect(
    criteria = SmartConnectCriteria(
        preferredCountry = "US",
        preferredCity = "New York",
        preferredRegion = "Virginia",
        maxLatency = 100,
        minCapacity = 20
    ),
    strategy = SelectionStrategy.BALANCED
)

Purpose-Built Methods

// Best server near user's location
sdk.smartConnectByLocation(strategy = SelectionStrategy.BALANCED)

// Optimized for streaming
sdk.smartConnectForStreaming(country = "US")

// Optimized for P2P
sdk.smartConnectForP2P(country = "NL")

// By physical region
sdk.smartConnectByRegion("Virginia")
Note: The region parameter is a physical province/state name (e.g., "Virginia", "Punjab"), not a cloud region code.
